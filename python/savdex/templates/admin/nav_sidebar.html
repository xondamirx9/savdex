{% load i18n %} {% comment %} Меню слева — как у Django (admin/nav_sidebar.html), плюс одно: место прокрутки меню переживает переход по разделам. Каждый щелчок в меню — новая страница, и Django рисует меню с самого верха: открытый раздел внизу списка уезжал из виду. Перед уходом со страницы прокрутка меню запоминается во вкладке (sessionStorage) и ставится обратно сразу за меню, до того как страница дорисуется. Если открытый раздел всё равно не виден (пришли не из меню) — меню прокручивается к нему. {% endcomment %}
