Как устроена книга

Формат XLSX, можно выбрать сразу несколько файлов (до {{ max_workbooks }}). В книге до пяти листов, по одному на язык: «Русский», «English», «O‘zbekcha», «中文», «Türkçe» — как в образце. Первая строка листа — названия столбцов, дальше по строке на товар.

Русский лист главный: цена, валюта, категория, компания, город и фотографии берутся с него. На остальных листах — заголовок, описание, условия поставки и оплаты на своём языке, строка к строке с русским листом: число строк должно совпадать, иначе этот язык пропустится, а товары загрузятся без него.

Пустые и неполные данные загрузку не останавливают: пустая ячейка пропускается, строка без заголовка или компании не загружается, но остальные строки идут дальше; неподходящий лист перевода пропускается. Всё пропущенное перечислено в отчёте под кнопкой.

Нет строки с названиями столбцов или они названы по-своему — загрузка определит столбцы по содержимому (длинный текст — описание, «Раздел → Подраздел» — категория, CIF и «самовывоз» — условия поставки и так далее) и напишет в отчёте, что каким столбцом стало.

Фотографии вставьте прямо в русский лист, в строку своего товара: сколько снимков в строке, столько и попадёт в объявление (до {{ max_images }}). Формат снимков любой, какой открывает Excel.

Строка с «Номером» правит объявление с этим номером, без номера — ищется по названию и компании, не нашлось — заводится новое. Новые объявления попадают в «На проверке» — опубликуйте их из списка.

Столбец «Компания» пуст — например, в книге заявок, собранных с других площадок? Укажите выше «Компанию для строк без компании»: ей достанутся такие строки. Столбца «Тип» нет — новые объявления получат тип из окна загрузки: для заявок на покупку выберите «Запрос».

Незаполненная ячейка ничего не ломает: пустое поле просто останется пустым. Ячейку, которую загрузка не понимает — категории нет в каталоге, валюты нет у площадки, — она пропустит, а товар загрузит и напишет об этом в отчёте.
