# Миграции схемы (этап 8)

Изменения схемы базы после ухода Laravel: файл `<дата>_<что>.sql`
с именем в духе миграций Laravel (`2026_11_01_000000_add_x_to_y.sql`) —
по имени идёт порядок. `manage.py schema` (при каждом запуске
контейнера) применяет каждый файл один раз, целиком в одной транзакции,
и записывает имя в таблицу `migrations`. Права роли `savdex_django`
на новые таблицы файл выдаёт сам — пример в `savdex/schema.py`.
