# Договор ILMORA

Текст договора для страницы `/ilmora/contract` (savdex/ilmora/views.py):

- `ru.txt` — по-русски, `uz.txt` — по-узбекски;
- обычный текст, абзацы разделяются пустой строкой;
- `[ФИО]` в тексте — сюда страница сама подставит фамилию, имя и
  отчество из анкеты (как в первой строке «Я, [ФИО], …»);
- пока файл пуст, под первой строкой написано «Полный текст договора
  будет опубликован позже».

Первая строка «Я, [ФИО], ознакомился(-ась) с настоящим договором…» —
в словарях интерфейса (`ilmora.contract.preamble` в
`savdex/locale/ui/ru.json` и `uz.json`).

Вставили настоящий текст — смените `CONTRACT_VERSION` в
`savdex/ilmora/views.py` (например на дату публикации): у новых заявок
в базе будет новая версия, у старых останется прежняя.
