# Публичная оферта ILMORA

Текст для страницы `/ilmora/offer` (savdex/ilmora/views.py):
`ru.txt` — по-русски, `uz.txt` — по-узбекски. Абзацы разделяются
пустой строкой. Начало строки задаёт вид:

- `# …` — заголовок документа («ПУБЛИЧНАЯ ОФЕРТА», «ЗАЯВЛЕНИЕ»);
- `### …` — подзаголовок под ним;
- `## …` — заголовок раздела («1. Общие положения»);
- `~ слева | справа` — строка «город — редакция»;
- `> …` — строка справа (кому адресовано заявление);
- `---` — разделитель (перед приложением);
- остальное — обычный абзац.

Метки, которые страница заполняет сама из анкеты:

- `[ФИО]` — фамилия, имя, отчество;
- `[НОМЕР_НАЗВАНИЕ]` и `[НОМЕР]` — «ПИНФЛ» и номер у физлица, «ИНН» и
  номер у юрлица;
- `[ТЕЛЕФОН]` — +998 и номер;
- `[ДАТА]` — дата и время;
- `[ОТМЕТКА_ОФЕРТА]`, `[ОТМЕТКА_ПОДПИСЬ]` — ☐ или ☑ по галочкам анкеты.

Не заполнено в анкете — на месте метки черта «______________».

Новая редакция — смените дату в тексте и `OFFER_VERSION` в
`savdex/ilmora/views.py`: у новых заявок в базе будет новая редакция,
у старых останется прежняя.
