# Публичная оферта ILMORA

Текст оферты для страницы `/ilmora/offer` (savdex/ilmora/views.py):

- `ru.txt` — по-русски, `uz.txt` — по-узбекски;
- обычный текст, абзацы разделяются пустой строкой;
- пока файл пуст, страница пишет «Текст оферты будет опубликован позже».

Вставили настоящий текст — смените `OFFER_VERSION` в
`savdex/ilmora/views.py` (например на дату публикации): у новых заявок
в базе будет новая версия, у старых останется прежняя.
