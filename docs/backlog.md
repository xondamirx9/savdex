## 3. Автоматизация

Сегодня лиды, обращения и коммуникации заводятся руками. Каждый пункт —
отдельная работа, порядок примерно по возрастанию сложности.

| Что | Как должно работать |
|---|---|
| Форма обратной связи → лид | Заполнил форму на сайте — лид появился в CRM сам, с источником |
| Письмо на почту поддержки → обращение | Письмо на support@ становится обращением, ответ уходит тем же письмом |
| Оплата → сделка | Прошедший платёж закрывает сделку без ручной отметки |

Пока этого нет, менеджер переносит данные руками — и переносит не всё.

## 4. Инфраструктура

### 4.1. Переезд сервера ближе к Ташкенту

**Решено (сентябрь 2026): пока не переезжаем.** Сервис и база остаются
в Орегоне. Цена переезда — новые сервис и база и ещё один перенос данных:
регион базы после создания не меняется. Вернуться к вопросу, если
медлительность админки станет мешать работе; мерить так: DevTools →
Network → `livewire/update` → Timing → Waiting (TTFB) — 250–400 мс при
ответе в пару килобайт означают дорогу, а не код.

### 4.2. Тариф базы

`basic-256mb` — 256 МБ на PostgreSQL. Кэш из неё уже убран, сессии остались
(3 запроса на страницу против 14 у кэша). Решать по логам после того, как
станет видно поведение без AhrefsBot.

### 4.3. Сессии в Redis

Не нужно, пока экземпляр сервиса один. Понадобится второй — файловый кэш
разъедется между ними, и тогда кэш и сессии переезжают в Render Key Value,
а не обратно в базу.

### 4.4. Удалить базу Neon

**Решено удалить (сентябрь 2026), удаляется в панели Neon.** Сайт работает
с базой Render (сервер `dpg-…`), Neon не используется с переезда.
Перед удалением — убедиться, что ни одна переменная службы на Render
не ведёт в Neon (в Shell, пароль скрыт):

```bash
env | grep -i neon | sed 's/:[^:@]*@/:***@/'
```

Пусто — можно удалять: console.neon.tech → проект → Settings → Delete
project. После удаления строка уходит из списка.

### 4.5. Ручной деплой в Render

Кнопка ручного деплоя не работает («Access to the Git repository was
denied»), автоматические деплои проходят. **Решено (сентябрь 2026): в
поддержку не обращаемся**, автоматических деплоев достаточно.
