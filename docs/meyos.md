# Интеграция с MEYOS

MEYOS — Ассоциация предприятий мебельной и деревообрабатывающей
промышленности Узбекистана (meyos.uz). SavdEx отдаёт ей мебельные
объявления площадки в JSON и принимает от неё товары производителей —
тоже в JSON (раздел «Приём объявлений» ниже).

## Что отдаём

Опубликованные объявления:

- раздела «Мебель» и его подразделов (офисная мебель, мебель для дома,
  другое);
- других категорий, если в заголовке есть мебельное слово (ДСП, ЛДСП,
  МДФ, фурнитура, столешница, шкаф, диван…). Слово ищется с начала
  слова; список правится в админке: «Настройки площадки» → «Интеграции»
  → «Мебельные слова».

Телефонов и почты продавцов в выгрузке нет: на SavdEx контакт
открывается за плату. В каждой записи — ссылка на объявление и на
страницу компании, по ним покупатель переходит на площадку.

## Как получить

Админка → «Объявления» → «Выгрузка» → «Ссылка для MEYOS»
(`/py/admin/integrations/meyos/`, право «Интеграции»):

- **Скачать JSON** — файл для отправки вручную;
- **Постоянная ссылка** — `https://savdex.uz/feeds/meyos.json?key=…`:
  сайт MEYOS забирает свежий список сам. По умолчанию выключена.
  «Выдать новую ссылку» меняет ключ — прежняя ссылка сразу перестаёт
  работать. Выключенная ссылка и чужой ключ — ответ 404.

Каждое действие на странице — строка журнала действий (ключ туда не
пишется).

## Формат

```json
{
  "source": "savdex.uz",
  "generated_at": "2026-10-04T08:03:12+00:00",
  "count": 1,
  "items": [
    {
      "id": 1,
      "url": "https://savdex.uz/listing/ofisnyy-stol-rukovoditelya",
      "type": "supply",
      "title": "Офисный стол руководителя",
      "title_i18n": {"uz": "Rahbar uchun ofis stoli"},
      "description": "…",
      "category": {
        "id": 26, "slug": "ofisnaya-mebel", "name": "Офисная мебель",
        "parent": {"id": 25, "slug": "mebel", "name": "Мебель"}
      },
      "price": 1500000,
      "bundle_price": null,
      "currency": "UZS",
      "unit": "шт",
      "price_negotiable": false,
      "min_order": 1,
      "delivery_terms": "",
      "payment_terms": "",
      "city": "Ташкент",
      "company": {"id": 1, "name": "Мебель Плюс", "url": "https://savdex.uz/company/mebel-plus"},
      "photos": ["https://savdex.uz/storage/listings/1/a.jpg"],
      "published_at": "2026-10-04T08:03:12+00:00",
      "updated_at": "2026-10-04T08:03:12+00:00"
    }
  ]
}
```

| Поле | Что это |
|---|---|
| `id` | Номер объявления на SavdEx — постоянный, по нему обновлять запись у себя |
| `url` | Страница объявления на SavdEx |
| `type` | `supply` — продаю, `demand` — покупаю (запрос на закупку) |
| `title`, `description` | Заголовок и описание на русском |
| `title_i18n` | Заголовок на других языках: `uz`, `en`, `zh`, `tr` (есть не всегда) |
| `category` | Подраздел и его раздел (`parent`) |
| `price` | Цена за единицу; `null` — не указана |
| `bundle_price` | Цена за весь комплект, если продаётся комплектом |
| `currency` | `UZS`, `USD`, … |
| `unit` | Единица: шт, м², комплект… |
| `price_negotiable` | Цена договорная |
| `min_order` | Минимальный заказ, в единицах |
| `delivery_terms`, `payment_terms` | Условия поставки и оплаты |
| `city` | Город объявления |
| `company` | Продавец: название и страница на SavdEx (без контактов) |
| `photos` | Фотографии по порядку, первая — обложка |
| `published_at`, `updated_at` | Когда опубликовано и когда менялось (UTC) |

Объявление, которого больше нет в списке, снято с публикации или
удалено — у себя его тоже стоит скрыть.

## Приём объявлений

Та же страница «Ссылка для MEYOS» → «Принять объявления от MEYOS»
(право загружать объявления, как у загрузки из Excel). Файл — JSON
в том же виде, что выгрузка: `{"items": [...]}` или просто `[...]`.

```json
{
  "items": [
    {
      "savdex_id": null,
      "title": "Диван угловой «Мадрид»",
      "title_i18n": {"uz": "Burchak divan «Madrid»"},
      "description": "Ткань велюр, 280×180 см",
      "description_i18n": {"uz": "…"},
      "type": "supply",
      "company": {"name": "Мебель Плюс", "tin": "301234567"},
      "category": {"name": "Мебель для дома", "parent": {"name": "Мебель"}},
      "city": "Ташкент",
      "price": 7500000,
      "price_negotiable": false,
      "currency": "UZS",
      "unit": "шт",
      "min_order": 1,
      "delivery_terms": "По Ташкенту бесплатно",
      "payment_terms": "Предоплата 50%",
      "photos": ["https://example.uz/photos/divan-1.jpg"]
    }
  ]
}
```

| Поле | Обязательно | Как понимается |
|---|---|---|
| `title` | да | Заголовок на русском; без него запись не загружается |
| `savdex_id` | нет | Номер объявления на SavdEx — если правите уже загруженное. Без него объявление ищется по заголовку и компании |
| `company` | желательно | Объект `{"name", "tin"}` или строка. Сначала ищется по ИНН (`tin`), потом по названию. Компании нет на SavdEx — объявление достаётся компании, выбранной в окне загрузки, а если там пусто — служебной (её объявления потом передают владельцу действием «Передать компании…») |
| `category` | желательно | `{"name", "parent": {"name"}}` или строка «Мебель → Мебель для дома». Неизвестный подраздел — раздел с заметкой |
| `type` | нет | `supply` — продаю, `demand` — покупаю; без него — по заголовку («Куплю…») или из окна |
| `price`, `currency`, `unit`, `min_order` | нет | Цена за единицу; `price_negotiable: true` без цены — «договорная» |
| `city` | нет | Название города из справочника |
| `title_i18n`, `description_i18n`, `delivery_terms_i18n`, `payment_terms_i18n` | нет | Переводы: `uz`, `en`, `zh`, `tr` |
| `photos` | нет | Ссылки на картинки (http/https), до 10 штук, до 10 МБ каждая |

Как загружается — так же, как книга Excel:

- новое объявление ждёт проверки, если в окне не отмечено «Сразу
  опубликовать»; галочка публикует и ждавшие проверки с прошлой загрузки;
- повторная загрузка того же файла обновляет объявления, а не заводит
  дубли; пустое поле ничего не стирает;
- запись, которую не загрузить (например, без заголовка), — в отчёте на
  странице, остальные загружаются;
- фотографии скачиваются по ссылкам; ссылка на внутренний адрес
  (localhost, 10.x, 192.168.x…) не скачивается. Фото, которое не
  скачалось, — заметка в отчёте, объявление загружается без него;
- строка журнала «Загрузка»: «MEYOS, JSON: записей N, создано…».

## В самой админке

Окно «Выгрузка» в разделе «Объявления» выгружает любые объявления —
в Excel, CSV или JSON, по категориям (кнопка «Мебель и всё, что с ней
связано»), статусу и типу. Его JSON — тот же формат плюс служебные поля
для своих: `admin_url`, `status`, `status_name`, `expires_at`, `views`,
`impressions`, `unlocks`. Код — `python/savdex/data/listing_export.py`,
`python/savdex/data/meyos.py` и `python/savdex/data/json_import.py`.
